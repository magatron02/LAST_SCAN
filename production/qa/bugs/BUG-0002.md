## Environment
- **Build**: Introduced/observed at `4a11a31`; source unchanged through `9617dee` (`ls_main`)
- **Platform**: Windows, desktop web browser, keyboard and PointerLock
- **Scene/Level**: Prototype point-cloud room
- **Game State**: NAVIGATE mode with a WASD key held during Alt-Tab or OS focus change

## Reproduction Steps
**Preconditions**: Start the prototype and acquire PointerLock.

1. Press and hold `W`.
2. Alt-Tab away from the browser before releasing `W`.
3. Release `W` while another application has focus.
4. Return to the browser and reacquire PointerLock by clicking the overlay.
5. Do not press `W` again and observe movement.

**Expected Result**: Input state is cleared when focus or PointerLock is lost, so the player remains stationary after returning until a new movement keydown occurs.

**Actual Result**: The browser may not deliver the `keyup` event to the game. `KeyW` remains in the global `keys` set and movement resumes automatically when PointerLock is reacquired, continuing until a later `W` keyup reaches the page.

## Technical Context
- **Likely affected files**: `src/main.js:42-50`, `src/main.js:60-70`
- **Related systems**: FPS Movement, PointerLock lifecycle, Scan Mechanic input lock
- **Possible root cause**: The code adds and removes keys only on `keydown` and `keyup`. It does not clear the set on `blur`, `visibilitychange`, or PointerLock `unlock`.
- **Design context**: `design/gdd/fps-movement.md:86-87`, `:289-291`, and Open Question 1 at `:426-429`.

## Evidence
- **Static evidence**: `src/main.js:48-50` creates a persistent key set with no focus-loss reset path; `src/main.js:60-70` consumes that set as soon as controls are locked again.
- **Syntax check**: `node --check src/main.js` passed on 2026-06-27.
- **Runtime verification**: Manual reproduction required. Automated browser testing loaded the game successfully but could not acquire PointerLock because browser automation does not satisfy the required user gesture.

## Notes
Recommended implementation direction: clear the key set on `window.blur` and when the document becomes hidden.
